# Silicon Wafer Defect Classification

## Project Overview
This project aims to reproduce a machine learning research paper on Silicon Wafer Defect Classification using the WM-811K dataset. It is structured to be developed progressively across multiple assignments.

## Setup Instructions
This project is configured to run primarily in Google Colab. The codebase is maintained in GitHub and synchronized with Colab for execution.

To prepare the environment for Colab:
1. Ensure the raw dataset is extracted to `data/raw/`.
2. Push the codebase to a GitHub repository (excluding `data/raw/` and `data/processed/`).
3. Clone the repository into Google Colab.
4. Install dependencies specified in `requirements.txt`.
5. Re-upload or mount the dataset directly in the Colab environment.
