# Project Guidelines

## Assignments
- **Assignment 1**: Data preprocessing
- **Assignment 2**: Exploratory data analysis
- **Assignment 3**: Baseline ML models
- **Assignment 4**: Reproduction of selected research paper
- **Assignment 5**: Model comparison/evaluation
- **Assignment 6**: Proposed novel improvement
- **Assignment 7**: Final evaluation and conclusion

## Dataset
- **WM-811K / Silicon Wafer Defect Dataset**
- Raw data must reside in `data/raw/` and should never be modified directly.
- Processed data should be saved to `data/processed/`.

## Workflows
- All Python execution should happen within Google Colab.
- The local environment is strictly for codebase maintenance, file structuring, and version control via Git.
